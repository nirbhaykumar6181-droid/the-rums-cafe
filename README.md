# The Rum's Cafe

A premium, cinematic hospitality website and reservation platform for The Rum's Cafe.

> This is the Phase 1 foundation bundle. Business-specific facts, menu entries, prices, hours, booking policies and seating capacity must be verified with the cafe before publication.

## Stack
- Next.js App Router, React, TypeScript
- Tailwind CSS
- Framer Motion
- Supabase: PostgreSQL, Auth and Storage
- Resend for transactional email
- Vercel deployment

## Start locally
1. Install Node.js 20.9+.
2. Run `npm install`.
3. Copy `.env.example` to `.env.local` and fill values when services are configured.
4. Run `npm run dev`.
5. Open `http://localhost:3000`.

The initial page is a design-system and project scaffold, not a finished live website. Reservations and admin operations are not enabled until their backend phases are implemented and tested.
