# Delivery roadmap

## Phase 1 — foundation and discovery
- Confirm repository and project scope.
- Establish stack, architecture, security boundaries and approval register.
- Create starter app scaffold and project documentation.
- Audit the current cafe website and collect approved brand assets/content.

## Phase 2 — customer experience
- Build responsive shared layout, navigation and footer.
- Implement Home, About, Menu, Gallery and Contact with verified content.
- Add reusable motion components and accessible interactions.

## Phase 3 — data and reservation backend
- Create Supabase schema, migrations and RLS policies.
- Implement server-side availability and concurrency-safe reservation creation.
- Add validation, spam controls, booking references and email notifications.

## Phase 4 — admin
- Authentication, roles and protected routes.
- Reservation operations, hours/closures, tables, menu, gallery and settings.
- Audit log and basic analytics.

## Phase 5 — quality and launch
- Functional, security, accessibility and responsive testing.
- SEO metadata, sitemap, robots, structured data based on verified details.
- Preview deployment, owner review, production deployment and domain connection only with authorization.

## Definition of done
A feature is complete only when implemented, tested, accessible, and documented. No demo-only button may be presented as a live capability.
